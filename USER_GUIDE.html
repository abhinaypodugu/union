Union — User & Testing Guide

Complete navigation flows, Mobile + OTP onboarding, Admin Organization Setup, and Member Join guide for the Union platform.

"Geography determines jurisdiction. Functional groups determine membership. Committees determine responsibility. Permissions determine access. Issues follow a configured resolution workflow." — PRD §1.3

1. Mobile + OTP Welcome & Setup Flows

The Welcome screen asks only for a Mobile Number followed by 6-digit OTP verification, sent and checked by Supabase Auth.

Path A: Platform Super Admin (Create Organization & Share Code)

Only Platform Super Admins can create organizations. An operator registers their phone number in the platform_admins table (see docs/OPERATIONS.md). There is no setup key in the app.

  1. Mobile + OTP Verification: Enter your mobile number and the 6-digit code; registered Platform Super Admins are taken to the organization wizard.
  2. Step 1 of 3 (2 Questions): Enter the official Organization Name and choose a unique Organization Code (e.g. NHWU).
  3. Step 2 of 3 (2 Questions): Enter the Organization Description and configure governance terms (Case label & Group label).
  4. Step 3 of 3 (2 Questions): Enter the Founding Administrator Name, Headquarters City, and Work Email.
  5. Share Invite Code Screen: Once saved to Supabase, Union displays the Organization Invite Code with a Share organization code button so you can send the code to members.

Path B: Member Setup (Join via Shared Organization Code)

  1. Mobile + OTP Verification: Enter your 10-digit mobile number and verify the 6-digit OTP code.
  2. Step 1 of 3 (1 Question): Enter the Organization Code shared by your administrator (validated live against Supabase).
  3. Step 2 of 3 (2 Questions): Enter your Full Name and Email Address.
  4. Step 3 of 3 (2 Questions): Enter your City / Branch and Trade Sector / Group, then tap Complete Setup to persist your profile to Supabase and open the Home screen.

Returning Users

Verifying an already-registered mobile number via OTP automatically restores the user's profile and organization from Supabase and signs directly into the Home screen.

2. Member Application Flows

Flow 1: Clean Home Feed & Official Announcements

Switch between For you, My groups, and Announcements filters pinned directly below the header. Official announcements feature verified check-seals, serif display titles, and blue flag headers.

Flow 2: Groups & Communities

Displays enrolled geographic places (City, State, National) and trade functional groups. Private committee channels remain isolated by governance permissions.

Flow 3: Raising an Issue (Automated Routing)

Tap + Raise on the Issues tab. Fill in Category, Title, Description, and the "Affects other members" checkbox. The routing engine assigns it to the accountable committee and persists it to Supabase.

Flow 4: Tracking Grievances & Escalation Timeline

Tap any case card to view the status badge, deadline timer, and three-stage progress timeline (City L1 → State L2 → National L3).

3. Leadership & Administration Flows

  • Management Overview (/manage): Displays your Member Invite Code with a one-tap Share code button, open case metrics, and pending approvals.
  • Issue Queue (/manage/queue): Filter by All open, Unassigned, Overdue, and Escalated. Claim, assign handlers, escalate with mandatory justification, or resolve cases.
  • Committees & Appointments (/manage/committee): Manage committee rosters, terms, and Platform Super Admin overrides.
  • Broadcast Announcements (/manage/announce): Publish official announcements to targeted audiences persisted in Supabase.

4. Live Supabase Persistence

All OTP sessions, organizations (tenants), member profiles (profiles), committees (committees, committee_members), geographic units (geo_units), functional groups (functional_groups), grievances (issues), posts (posts), and audit logs (audit_logs) are persisted live to Supabase PostgreSQL.
