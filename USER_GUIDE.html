Commons Platform — User & Testing Guide

Complete navigation flows, persona testing guide, and feature specifications for everyday members and leadership.

"Geography determines jurisdiction. Functional groups determine membership. Committees determine responsibility. Permissions determine access. Issues follow a configured resolution workflow." — PRD §1.3

1. Quick Start & Access Methods

  • Option A (Android .apk): Download from GitHub Actions artifacts and install directly on Android.
  • Option B (Expo Go on iPhone): Run npx expo start, scan QR code with Camera app.
  • Option C (PWA on iPhone): Open in Safari → Tap Share → Add to Home Screen.

3. Member Application Flows

Flow 1: Home Feed & Official Announcements

Explore the Instagram-inspired feed. View circular group stories for Hyderabad, Telangana, and IT Workers. Switch between For You, My groups, and Announcements filters. Official announcements feature verified check-seals, serif display titles, and blue flag headers.

Flow 2: Groups & Communities

Displays enrolled geographic places (City, State, National) and trade functional groups with real-time unread counts. Notice the privacy notice card confirming private committee channels are separated by governance.

Flow 3: Raising an Issue (Automated Routing)

Tap + Raise on the Issues tab. Fill in Category, Title, Description, and the "Affects other members" checkbox. The routing engine assigns it to the accountable committee based on category rules:

  • Harassment / Retaliation: Directly routed to Confidential Handlers at Tier 2 (State).
  • Facilities: Routed to General Committee.
  • Wages / Health & Safety: Routed to City Sector Committee (L1).

Flow 4: Tracking Grievances & Escalation Timeline

Tap any case card to view the status badge, deadline timer, and three-stage progress timeline (City L1 → State L2 → National L3). When the committee requests info, an amber alert appears allowing direct replies.

4. Leadership & Administration Flows

Flow 8: Accessing Management Tools

Tap the Shield icon (🛡️) in the top-right header on the Home screen or go to Profile → Leadership tools.

Flow 9: Issue Queue & Case Management

In /manage/queue, filter by All open, Unassigned, Overdue, and Escalated. Tap any case to claim it, assign an officer, or escalate.

Flow 10: Tiered Escalation with Mandatory Reason

Tap Escalate. Enter the mandatory reason (e.g. "Local employer refused to engage in 14-day SLA window"). Tier increments L1 → L2 with an audit log record and complainant notification.

Flow 11: Platform Super Admin Override

Switch persona to Dr. Vikram Patel. In Committees & appointments, tap + Add. Toggle Platform Super Admin override, provide justification reason, and save. The member receives a distinct red Platform-admin override badge.

Flow 12: Organization Creation via UI

In Profile → Organization context → tap + Create new organization (PRD §5.11). Establish a new isolated organization boundary with custom terminology mapping directly from the app.

5. Database & Supabase Mode

When EXPO_PUBLIC_SUPABASE_URL is configured in .env, the app runs in 100% Live Database Mode using PostgreSQL tables defined in supabase/schema.sql with real-time subscriptions and Row Level Security.
